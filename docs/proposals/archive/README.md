# Archived Proposals

This directory contains proposals that are:
- **Implemented** - Completed and merged, kept for historical reference
- **Rejected** - Not approved, kept for context on why decisions were made
- **Superseded** - Replaced by newer proposals

## Archive Policy

Proposals are moved here when:
- 6 months after implementation (status: Implemented)
- Immediately after rejection (status: Rejected)
- When a new proposal supersedes an old one (status: Superseded)

## Format

Archived proposals maintain their original filename format:
`IMPL-YYYY-MM-DD-<short-name>.md`

Add archival metadata at the top:
```markdown
**ARCHIVED:** YYYY-MM-DD
**Reason:** Implemented in v2.2.0 | Rejected - reason | Superseded by IMPL-YYYY-MM-DD-new-name
```
